## 8. Root Cause 分析：RCE vs StarRC 配置差异

### 8.1 RC 文档对比分析

| 功能 | StarRC (Golden) | RCE | 状态 |
|:----|:--------------|:---|:----:|
| **电阻源** | `TCAD_GRD_FILE` (NXTGRD 3D场求解) | `TABLE` (captab 查表) | 不同 |
| **跳过器件体电阻** | `LPE_PARAM: rctmod NORC 1 C 1 R 0 RC 0` | `LPE_PARAM` 支持相同语法 | 但设计中无 rhrpo 电阻单元 |
| **识别电阻器件** | `CALIBRE_LVS_DEVICE_TYPE_RES : rhrpo_2t_ckt` | `LVS_DEVICE_TYPE_RES : rhrpo_2t_ckt` | 已尝试——设计中无 rhrpo 单元 |
| **跳过指定层电阻** | `HIGH_R_LAYERS` | `RES_SHORT_LAYER` | 文档有但 RCE 2026.03 不支持 |
| **层电阻缩放** | `RC_SCALING_FILE` | `RES_SCALING_LAYERS` | 文档有但 empExtract 不识别 |
| **跳过层提取** | 无直接对应 | `RES_OPEN_LAYER` | 文档有但不支持 |
| **修改 captab SHEETR** | N/A | `SHEETR 0.0001` | 修改后 RCE 解析崩溃 |

### 8.2 StarRC 的关键做法

```makefile
# StarRC 通过 LPE_PARAM 明确跳过电阻器件的体电阻提取
LPE_PARAM: rctmod  NORC 1 C 1 R 0 RC 0
LPE_PARAM: rctpmod NORC 1 C 1 R 0 RC 0

# RCE 对此的等效配置:
LPE_DEVICES : rctmod rhrpo_2t_ckt rhrpo_3t_ckt
LPE_PARAM : rctmod NORC 1 C 1 R 0 RC 0
```

但此方法**仅适用于设计中显式实例化的电阻器件**（rhrpo_2t_ckt）。对于本设计，多晶硅电阻来自 MOSFET 的栅极多晶互联层（field poly），StarRC 通过 `LPE_PARAM: rgtmod NORC 1 C 1 R 0 RC 0` 跳过，RCE 则无对应机制。

### 8.3 已尝试的修复路径

| 尝试 | 方法 | 结果 |
|:---|:----|:----:|
| 1️⃣ | `LVS_DEVICE_TYPE_RES : rhrpo_2t_ckt rhrpo_3t_ckt` | ❌ 设计中无 rhrpo 单元 |
| 2️⃣ | `RES_OPEN_LAYER : io_npoly io_ppoly` | ❌ empExtract 不识别 |
| 3️⃣ | `RES_SHORT_LAYER : npoly_io ppoly_io` | ❌ empExtract 不识别 |
| 4️⃣ | 修改 captab SHEETR → 0.0001 | ❌ RCE 解析崩溃 |
| 5️⃣ | `RES_SCALING_LAYERS : io_npoly 0 io_ppoly 0` | ❌ empExtract 不识别 |

RCE 2026.03 版本的 empExtract 翻译器只识别 `ext_option_default` 中列出的参数子集，`RES_SHORT_LAYER`、`RES_OPEN_LAYER` 等未包含在翻译表中。

### 8.4 根因结论

```
RCE 额外提取的 82,803 Ω 中:
  61.3% (50,831 Ω) 来自 ppoly_io + npoly_io → 多晶电阻器体电阻
  27.7% (22,901 Ω) 来自 DIFF_N → N+扩散区电阻  
  11.0% (9,071 Ω)  来自其他层 → 金属互联电阻差异

核心原因:
  StarRC 通过 LPE_PARAM: R 0 跳过栅极多晶和扩散区电阻
  RCE 无法跳过这些层的电阻提取
```

## 9. 综合结论

### 9.1 改进效果总结

| 阶段 | RCE Vout DC | Ref Vout DC | 状态 |
|:---:|:----------:|:-----------:|:----:|
| 初始 (NET_X/VDD缺失) | 48.87 mV | 46.60 mV | ❌ |
| 加NET_X | 21.22 mV | 15.12 mV | ✅ |
| **当前 (完整提取)** | **21.22 mV** | **15.12 mV** | **✅ Ref已接近Golden** |

### 9.2 主要差异

| 差异类型 | 说明 | 影响程度 |
|:--------|:----|:--------:|
| **电容欠提** | RCE 总电容比 Golden 低 22%，主要缺内部信号节点(NET_PBIAS, NET_S等) | 中等 |
| **电容过提** | Ref 总电容比 Golden 高 16%，主要来自 VOUT(54.7fF vs 4.0fF) | 高 |
| **RCE 电阻过提** | RCE 比 Golden 高 ~178%，61% 来自 ppoly/npoly 体电阻 | **最高** |
| **Ref 电阻过提** | Ref 比 Golden 高 ~177% | **高** |
| **电源缺失** | 已修复，VDD/VSS 现在都存在 | 已解决 |
| **NET_X 缺失** | 已修复 | 已解决 |

### 9.3 改进建议

1. **RCE 跳过多晶电阻体电阻**（关键）
   - 修改 captab，将 npoly_io/ppoly_io 的 SHEETR 改为 0.0001（需确认 captab 格式兼容性）
   - 或在 LVS 阶段将 poly 电阻识别为器件，通过 LPE_DEVICES+LPE_PARAM 跳过
   - 或联系 Empyrean 确认是否有隐藏参数可处理此场景

2. **RCE 电容提取精度提升**
   - 增加 C 元素数量（从 2,581 到接近 Golden 的 6,374 个）
   - 检查 captab 电容模型参数

3. **GloryEX VOUT 电容过提**
   - Ref 的 VOUT 电容 (54.7fF) 是 Golden (4.0fF) 的 13 倍，需要检查提取配置

4. **层信息输出**
   - 建议 RCE 和 Ref 在 DSPF 中包含 `$lvl` 层信息，便于定位问题
